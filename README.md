# Página Pessoal — Larissa Rocha Silva

Projeto desenvolvido para a disciplina **GAC116 - Programação Web** (Atividade Prática 2).

Página pessoal (portfólio web) construída em **duas versões**, com o mesmo conteúdo, variando
apenas o framework CSS utilizado:

- **[`/bootstrap`](./bootstrap/index.html)** — versão construída com [Bootstrap 5](https://getbootstrap.com/).
- **[`/outro-framework`](./outro-framework/index.html)** — versão construída com [Tailwind CSS](https://tailwindcss.com/).

O arquivo [`index.html`](./index.html) na raiz é uma página de entrada com links para as duas versões.

## Tecnologias

- HTML5
- CSS3 (Bootstrap 5 e Tailwind CSS via CDN)
- JavaScript (alternância de tema claro/escuro com persistência em `localStorage`)

## Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Tema claro e tema escuro, com detecção da preferência do sistema e opção de alternar manualmente
- Seções: Sobre, Habilidades, Projetos e Contato

## Como visualizar localmente

Basta abrir o arquivo `index.html` diretamente no navegador.

## Publicação (GitHub Pages)

1. Faça push deste repositório para o GitHub.
2. Em **Settings → Pages**, selecione a branch `main` e a pasta raiz (`/`).
3. O site ficará disponível em (https://github.com/lari030/Pagina-Pessoal/tree/main)
